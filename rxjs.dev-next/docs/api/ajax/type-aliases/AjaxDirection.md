# Type Alias: AjaxDirection

## Description

Valid Ajax direction types. Prefixes the event `type` in the
[AjaxResponse](../classes/AjaxResponse.md) object with "upload_" for events related
to uploading and "download_" for events related to downloading.

```ts
type AjaxDirection = "upload" | "download";
```
